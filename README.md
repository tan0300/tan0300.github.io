# Jonathan Español — Portfolio

Public portfolio built with Vue 3 and Tailwind CSS.

## Quick test

Option 1: Open `index.html` directly in your browser.

Option 2: Run a local server:

```bash
cd portfolio-local
python3 -m http.server 8000
```

Then open:

http://localhost:8000

## Files

- `index.html` - main portfolio page
- `assets/style.css` - styles
- `assets/app.js` - simple navigation behavior
- `assets/images/` - project artwork

## Build styles

```bash
npm install
npm run build:css
```

The compiled website is static and ready for GitHub Pages.
